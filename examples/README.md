# Examples

Firmware examples for the ESP32 Modbus Adapter. Each one is a standalone ESP-IDF project, so build it from its own folder.

## Matter

| Example | Device | Matter device type |
|---------|--------|--------------------|
| [SDM120M](matter/SDM120M) | Eastron SDM120M single phase energy meter | Electrical Sensor |
| [SolaxX1G4](matter/SolaxX1G4) | Solax X1 Hybrid G4 inverter (PV strings and battery) | Solar Power, with Electrical Sensor and Power Source sub-parts |
| [KronotermAdapt](matter/KronotermAdapt) | Kronoterm Adapt 0312 air-to-water heat pump | Heat Pump, with Thermostat, Temperature Sensor and Water Heater sub-parts |
